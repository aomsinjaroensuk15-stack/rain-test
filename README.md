## ✨ ฟีเจอร์

- **⏱️ ไทม์ไลน์ฝน 24 ชม.** — รายชั่วโมง: ไอคอนสภาพอากาศ (กลางวัน/กลางคืน), โอกาสตก %, ปริมาณ มม., อุณหภูมิ พร้อมป้าย "ตอนนี้" และฝนรวมของวง 24 ชม.
- **🗣️ สรุปอัตโนมัติ** — แอปเขียนประโยคให้เอง เช่น *"ตอนนี้ฝนกำลังตก · ฝนจะหยุดราว 17:00 น."* หรือ *"ไม่มีฝนถึงพรุ่งนี้เวลานี้เลย"*
- **🎨 ท้องฟ้ามีชีวิต** — ธีมเปลี่ยนตามสภาพอากาศจริง 4 โหมด (ฟ้าใสกลางวัน / วันฝน / คืนฟ้าโล่ง / คืนฝน) เมฆลอย ฝนตกบนหน้าจอ ดวงอาทิตย์/จันทร์เรืองแสง
- **📍 3 วิธีเลือกตำแหน่ง** — GPS ของคุณ / ค้นหาชื่อที่ / แตะเลือกบนแผนที่ OpenStreetMap (พร้อม reverse geocode หาชื่อพื้นที่อัตโนมัติ)
- **⚡ ระดับความแรงฝน** — เบา / ปานกลาง / หนัก / หนักมาก ตัดสินจากปริมาณ มม. จริง (แสดงเป็นคำ ไม่ใช่สีอย่างเดียว) พร้อมป้ายระบุว่าเป็นค่าประมาณ
- **🔁 อัปเดตอัตโนมัติ** — รีเฟรชเองทุก 10 นาทีเมื่อเปิดแอป (ไม่กระชากจอ ไม่ดีดกลับขึ้นบน) แตะบรรทัดอัปเดตเพื่อรีเฟรชทันที
- **📲 PWA ติดตั้งได้** — ติดตั้งลงหน้าจอหลัก เปิดออฟไลน์ได้ทั้งตัวแอป (service worker) พร้อมข้อมูลฝนที่ cache ไว้

| 1 — แกนหลัก | ✅ เสร็จ | ฝน 24 ชม. (แสดงเป็นช่วงเวลา xx–xx น.) + สรุปอัตโนมัติ + GPS/ค้นหา/แผนที่ |

## 🛠️ เทคโนโลยี

- **ไฟล์เดียวล้วน** — HTML + CSS + JS ไม่มี build step ไม่มีเซิร์ฟเวอร์ฝั่งเรา
- **ข้อมูล** — [Open-Meteo](https://open-meteo.com) (CC BY 4.0) — พยากรณ์ + ความน่าจะเป็นฝน + geocoding ฟรี
- **แผนที่** — Leaflet + OpenStreetMap tiles
- **โฮสต์** — GitHub Pages

## ⚠️ ข้อจำกัดที่ต้องรู้

พยากรณ์มาจากโมเดลสภาพอากาศความละเอียดหลายกิโลเมตร **ไม่ใช่เรดาร์ตรวจจับฝนจริง** — ฝนเม็ดเดียวในซอยข้าง ๆ อาจไม่ตรงกับที่แอปบอกเสมอ เหมาะสำหรับวางแผน "พกร่มไหม / ออกไปตอนไหน" ไม่ใช่คำรับประกัน

## 🔒 ความเป็นส่วนตัว

- พิกัดถูกส่งตรงจากเบราว์เซอร์ของคุณไปยัง Open-Meteo (พยากรณ์) และ Nominatim (ค้นหา/ชื่อสถานที่) เท่านั้น
- เรา**ไม่มีเซิร์ฟเวอร์ของตัวเอง** ไม่มีฐานข้อมูล ไม่เก็บ ไม่ขายข้อมูลส่วนตัว
- ข้อมูลล่าสุดถูกเก็บไว้ในเครื่องของคุณเอง (localStorage) ลบได้ด้วยการล้างข้อมูลเว็บ
